# Settings

Every setting of the Workspace and the engine, with the environment variable that sets it on Docker and Kubernetes, its
default and what it changes. Generated from the descriptions in each app's
`META-INF/additional-spring-configuration-metadata.json` and the `application*.yml` files by
`scripts/settings-reference.py`; run it again after adding a setting.

Settings are layered, broadest first: defaults in `application.yml`, then environment variables mapped in
`application-docker.yml` (also read by the `k8s` profile), then a dataset's own `compute:` section for Spark. Beans only
bind `dataflow.*`; `env.*` names exist inside the yml files to carry environment variables to them. Settings →
Configuration in the Workspace shows the values in effect, with secrets masked.
